# LUMA Brand Extraction

Source: `LUMA Brand Guidlines.pdf`

The guide is a presentation PDF with limited machine-readable text in this environment, so the implementation treats the PDF as the identity source and codifies a restrained skincare system:

- Personality: luminous, soft, trustworthy, clean, elegant, sensory, warm.
- Tone: premium and calm; skincare-safe wording such as "supports", "helps", "nourishes", "designed for".
- Palette: warm ivory background, blush rose primary, muted botanical sage, clay accent, deep green-black text.
- Typography: editorial high-contrast headings paired with clean modern body text.
- Layout: airy spacing, rounded cards, soft shadows, balanced whitespace, gentle grid rhythm.
- Visual style: warm product photography, dewy skin, natural ingredients, translucent glass, soft gradients, liquid glow.
- Logo usage: keep "LUMA" clear, high-contrast, spacious, never squeezed into busy textures.
- Avoid: harsh neon colors, hard medical claims, cluttered ecommerce grids, aggressive discount language, heavy dark themes.

Design tokens in `frontend/src/styles/global.css` implement these rules as CSS variables.
